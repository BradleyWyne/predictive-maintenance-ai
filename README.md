# AI Predictive Maintenance System

## Overview
This project uses Machine Learning to predict equipment failure based on sensor data such as temperature, vibration, and pressure.

## Features
- Machine failure prediction using Random Forest
- Interactive dashboard with Streamlit
- Simple and lightweight dataset simulation

## Libraries used
- Python
- Scikit-learn
- Pandas
- Streamlit

## Dataset
The dataset includes:
- Temperature
- Vibration
- Pressure
- Failure (0 = Normal, 1 = Failure)
